阻断点 1 · CourseHallFragment 用了不存在的构造函数

Course.java 只提供了无参和九参两个构造函数，但 CourseHallFragment.java:47-50 写的是 new Course("数据结构", "李老师", "4.0", "30")。最省事的修法是直接在 Course.java 里补一个四参构造函数，让旧代码继续可用：

// entity/Course.java 里追加
public Course(String courseName, String teacher, String credit, String remain) {
    this.courseName = courseName;
    this.teacher = teacher;
    this.credit = Double.parseDouble(credit);
    this.selectedCount = Integer.parseInt(remain);
    this.capacity = 60;
}

不过更推荐的正解是：重构 CourseHallFragment 时统一改用九参构造器，一次把时间、地点、容量都填进去（效果图的课程卡需要这些字段）。

阻断点 2 · DbManager.searchclass 语法错误

第 73 行 List<Course> result= ArrayList; 不成立，第 74 行 query() 的列名参数位传成了条件字符串，参数个数也少一个。整段重写：

public List<Course> searchclass(int userid, String passwd) {
    SQLiteDatabase db = helper.getReadableDatabase();
    List<Course> result = new ArrayList<>();
    String sql = "select c.* from table_course c "
               + "inner join table_selection s on s.courseid = c.courseid "
               + "inner join table_user u on u.userid = s.userid "
               + "where u.username = ? and u.passwd = ?";
    Cursor cursor = db.rawQuery(sql, new String[]{String.valueOf(userid), passwd});
    while (cursor.moveToNext()) {
        Course c = new Course();
        c.courseId   = String.valueOf(cursor.getInt(cursor.getColumnIndexOrThrow("courseid")));
        c.courseName = cursor.getString(cursor.getColumnIndexOrThrow("coursename"));
        c.teacher    = cursor.getString(cursor.getColumnIndexOrThrow("teacher"));
        c.credit     = cursor.getDouble(cursor.getColumnIndexOrThrow("credit"));
        c.time       = cursor.getString(cursor.getColumnIndexOrThrow("time"));
        c.location   = cursor.getString(cursor.getColumnIndexOrThrow("location"));
        c.capacity   = cursor.getInt(cursor.getColumnIndexOrThrow("capacity"));
        result.add(c);
    }
    cursor.close();
    db.close();
    return result;
}
