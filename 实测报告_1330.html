三、两个隐藏硬伤（重点）

发现一：语言切换按钮被状态栏整个盖住 —— 所以你「怎么点都没反应」

你之前一直觉得「切语言失败」，其实 代码一点问题都没有。我用键盘 TAB 把焦点挪到那个按钮再按回车，日志立刻打出来了：

D LANG : 切换为: en
→ 界面文字全部变成英文：
   Welcome to Course Selection / Enter Student ID / Login /
   No account? Register / Forgot password? Reset /
   Forgot ID? Recover account / Semester: 2026-2027 Fall

真正的原因在这里（实测证据）：

状态栏窗口 : mAttrs={(0,0)(fillx136)}   ← 状态栏占屏幕顶部 136 像素
按钮 btn_lang: bounds="[370, 0][709, 132]"  ← 按钮整个落在 0~132，完全在状态栏底下
App 窗口     : mAttrs={(0,0)(fillxfill)}      ← 应用从 y=0 开始画（顶到最上面）

我用手指点 (539,66)、(539,125)、(420,90)、(680,120) 四个位置，日志一次都没出现； 而点 y=264 的输入框、y=359 的密码框立刻有反应。结论：y < 136 那一整条被系统状态栏吃掉了。

根因：build.gradle 里 targetSdk 37。从 Android 15（API 35）开始，新应用被强制 edge-to-edge—— 窗口自动铺满整屏（含状态栏底下），而布局里没有做 insets 处理，于是最上面那排控件就被状态栏压住了。 登录页的「EN/DE/中文」按钮、主页的「EN/DE/中文」按钮都在这个位置，等于两个都点不到。

建议改法（三选一，从好到省事）：
  1. 标准做法：在 LoginActivity / MainActivity 的根布局上挂一个 ViewCompat.setOnApplyWindowInsetsListener，把 systemBars().top 当作 paddingTop 加给根布局。 （MainActivity 已经 import 了 ViewCompat / WindowInsetsCompat，正好用得上）
  2. 一行搞定：给两个根布局（acti_login.xml 的 LinearLayout、activity_main.xml 的 LinearLayout）加 android:fitsSystemWindows="true"。
  3. 最省事（治标）：给 btn_lang 加 android:layout_marginTop="140px"。 能让它露出来，但下面所有内容整体位置仍然是贴着状态栏的，不推荐。

发现二：底部 4 个 Tab，只显示「当前选中」那一个，其他 3 个完全隐形

实测截图里，底栏永远只有你正在看的那一个名字：在选课大厅就只显示「选课大厅」，切到个人中心就只显示「个人中心」，另外三个位置全是空白。

界面树的证据也很直接 —— 整个底栏里只有一个文字节点：

<node text="选课大厅"
      resource-id=".../navigation_bar_item_large_label_view"
      selected="true" bounds="[66,2191][203,2240]" />
（这就是「大号标签视图」＝只有选中项才会出现的那个）

根因：bottom_nav_menu.xml 的 4 个 item 只有 android:title，一个 android:icon 都没写。 而 Material3 的 BottomNavigationView 默认 labelVisibilityMode="auto"： 当 item 数量 ≥ 4 时，只给「选中项」显示文字，未选中项只显示图标。你没有图标 → 未选中项就是一片空白。

建议改法（二选一，都是几行的事）：
  1. 在 activity_main.xml 的 BottomNavigationView 上加 app:labelVisibilityMode="labeled" → 4 个文字常显，马上就能看见（最快）。
  2. 或者给 bottom_nav_menu.xml 每个 item 补 android:icon（系统内置的如 @android:drawable/ic_menu_agenda 之类就能用），这才是效果图里的样子（图标 + 文字）。

五、建议的动手顺序

  1. 先修状态栏遮挡（5 分钟，一行 fitsSystemWindows）—— 修完语言切换立刻就能点了，你折腾最久的那个问题直接消失
  2. 再修底部导航（2 分钟，加 app:labelVisibilityMode="labeled"）—— 四个 Tab 一眼可见，这是最"像个 App"的一步
  3. 成绩查询 Tab：删掉，或加个占位页
  4. en / de 各补 4 条字符串 + 两处「功能开发中」资源化
  5. 去掉我的课表的占位标题、拆开卡片布局（课表里不该有「选课」）
  6. 最后才是卡片信息补全 / 配色 / 注册页 / 详情弹窗
