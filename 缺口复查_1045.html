你问过两次5. 语言切换仍然不生效

位置：MainActivity.java:27-31、LoginActivity.java:21-25（都未改动）

Configuration config = new Configuration();      // 空配置
config.setLocale(locale);
getResources().updateConfiguration(config, ...);

new Configuration() 是空对象；updateConfiguration 在 Android 7.0 后已废弃；AppCompatActivity（AppCompat 1.6.1）内部持有自己的 Configuration，会把改动盖回去。recreate() 重建后走同一条路 → 永远"点了没反应"。

唯一能生效的改法 —— 两个 Activity 都加：

@Override
protected void attachBaseContext(Context newBase) {
    Locale locale = new Locale(MainActivity.lang);
    Locale.setDefault(locale);
    Configuration cfg = new Configuration(newBase.getResources().getConfiguration()); // 克隆
    cfg.setLocale(locale);
    super.attachBaseContext(newBase.createConfigurationContext(cfg));
}

加上后要删掉 onCreate 里那 5 行改配置的代码。

P16. 课表页点"选课"会把已选人数虚增 1

位置：MyCoursesFragment.java:36-38

db.insertSelection(userid,courseid);        // 已选过 → CONFLICT_IGNORE 直接忽略，没插进去
